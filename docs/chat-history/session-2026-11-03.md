### 发现并修复的问题

**1. 后端依赖装不上（环境问题）**
- `npm ci` 报 ERESOLVE：`@nestjs/schematics@12.0.12` 要求 peer `typescript >=6.0.0`，但 package.json 锁的是 `^5.4.5`（lock 文件本身就自相矛盾）→ 用 `--legacy-peer-deps` 按原锁版本安装（该包只用于 `nest generate`，不影响构建运行）
- 原生模块编译失败：本机 npm 走 npmmirror 镜像、GitHub 不可达，better-sqlite3/bcrypt 回退源码编译时 node-gyp 下载 Node 头文件超时 → 手动下载头文件填入 gyp 缓存 + sharp 配 npmmirror 镜像后编译成功

**2. 前端依赖冲突（项目配置问题）**
- `vue-toastification@^1.7.14` 是 **Vue 2 版本**（peer 要求 `vue@^2`），与项目的 Vue 3 冲突 → 升级为 `^2.0.0-rc.5`（Vue 3 兼容版，导入方式不变）

**3. 前端构建失败（项目代码 bug）**
- 10 个组件里用了 `$bg-light`、`$border` 等 SCSS 变量，但**从未导入变量定义**（变量混在 global.scss 里，各样式块独立编译必然报 undefined variable）→ 拆分出 `_variables.scss`，并在 `vite.config.js` 加 `additionalData` 自动注入
